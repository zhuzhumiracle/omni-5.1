1. Use only PyTorch tensor operations.
2. Do NOT use Python math, numpy, or any Python loops.
3. Do NOT output any import statements.

5. The only function you output must be:

Anti-shortcut constraints:

- Altitude shaping must be smooth and secondary; obstacle-risk handling must take priority.

- If the reward can be maximized by rising when obstacles are near, add a near-obstacle vertical-motion penalty.
- Prefer a speed band: add both low-speed and high-speed penalties so the best behavior is neither too slow nor too fast.
